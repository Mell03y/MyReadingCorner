# My Reading Corner 📚🌷

Toz pembe, bej ve soft yeşil tonlarında kişisel dijital kitaplık / reading journal.

## Özellikler

- Kitap ekleme, düzenleme ve silme
- Kitap bazlı ayrı değerlendirme ekranı
- Detaylı puanlama
- Favoriler ve alıntılar
- Görsel "bookshelf" raf görünümü
- Aylık günlük sayfa tracker'ı
- Ay sonu değerlendirmeleri
- Yıl sonu "Best Book" adayları ve kazanan seçimi
- Verileri tarayıcıda `localStorage` ile saklama
- JSON yedek alma / geri yükleme

## GitHub Pages'ta yayınlama

1. Bu klasördeki dosyaları GitHub repository'sine yükle.
2. Repository → **Settings** → **Pages**
3. **Deploy from a branch** seç.
4. Branch olarak `main`, klasör olarak `/root` seç.
5. **Save**.

Birkaç dakika sonra siten:
`https://KULLANICIADIN.github.io/REPOSITORY-ADI/`

adresinde açılır.

## Önemli

Bu ilk sürümde bilgiler sunucuda değil, kullandığın tarayıcının `localStorage` alanında saklanır.
Bu yüzden başka cihazda otomatik görünmez. Üstteki **Export** butonuyla yedek alabilirsin.

Daha sonraki sürümde Supabase/Firebase eklenerek hesap girişi ve cihazlar arası senkronizasyon yapılabilir.
